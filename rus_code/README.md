# РусКод - Язык программирования на русском языке

## Описание

**РусКод** - это универсальный язык программирования полностью на русском языке, который:
- ✅ Не содержит ни одной английской буквы в синтаксисе
- ✅ Понимает естественную русскую речь
- ✅ Доступен для детей 7-8 лет
- ✅ Мощный для взрослых разработчиков
- ✅ Имеет богатую библиотеку функций

## Структура проекта

```
rus_code/
├── core/                    # Ядро языка
│   └── interpreter.py       # Интерпретатор РусКод
├── libs/                    # Библиотеки
│   ├── math_lib.py          # Математическая библиотека
│   ├── string_lib.py        # Библиотека работы со строками
│   └── graphics_lib.py      # Графическая библиотека
└── examples/                # Примеры программ
    └── примеры.rk           # Примеры кода на РусКод
```

## Быстрый старт

### Установка

```bash
cd rus_code
python3 core/interpreter.py
```

### Первый пример

Создайте файл `привет.rk`:

```
пусть имя равна "Мир"
написать_строку(плюс("Привет, ", имя))
повторить 3 раза написать_строку("Ура!")
```

Запустите:

```bash
python3 core/interpreter.py < examples/примеры.rk
```

## Синтаксис языка

### Переменные

```
пусть x равна 10
пусть имя будет "Алексей"
y равна 5
```

### Математические операции

```
# Через функции
результат равна плюс(5, 3)
разность равна минус(10, 4)
произведение равна умножить(6, 7)
частное равна разделить(20, 4)

# Через выражения
сумма равна 5 плюс 3
```

### Условия

```
если больше(возраст, 18) то написать_строку("Совершеннолетний")
если меньше(оценка, 60) то написать_строку("Не сдал")
```

### Циклы

```
повторить 10 раз написать_строку("Привет")
```

### Работа со строками

```
пусть текст равна "Привет мир"
написать_строку(длина(текст))
написать_строку(верхний_регистр(текст))
написать_строку(нижний_регистр(текст))
```

### Графика

```
пусть холст равна создать_холст(800, 600)
пусть круг равна нарисовать_круг(400, 300, 50, 'красный')
добавить_на_холст(холст, круг)
показать_холст(холст)
```

## Встроенные функции

### Математика
- `плюс(a, b)` - сложение
- `минус(a, b)` - вычитание
- `умножить(a, b)` - умножение
- `разделить(a, b)` - деление
- `степень(a, b)` - возведение в степень
- `корень(x)` - квадратный корень
- `модуль(x)` - абсолютное значение
- `округлить(x, n)` - округление
- `случайное_число(min, max)` - случайное число

### Строки
- `длина(s)` - длина строки
- `верхний_регистр(s)` - перевод в верхний регистр
- `нижний_регистр(s)` - перевод в нижний регистр
- `заменить(s, old, new)` - замена подстроки
- `разделить_строку(s, sep)` - разделение строки

### Логика
- `и(a, b)` - логическое И
- `или(a, b)` - логическое ИЛИ
- `не(a)` - логическое НЕ
- `равно(a, b)` - проверка на равенство
- `больше(a, b)` - проверка на больше
- `меньше(a, b)` - проверка на меньше

### Ввод-вывод
- `написать(x)` - вывод без перевода строки
- `написать_строку(x)` - вывод с переводом строки
- `спросить(prompt)` - ввод от пользователя

### Графика
- `создать_холст(width, height)` - создание холста
- `нарисовать_круг(x, y, r, color)` - рисование круга
- `нарисовать_квадрат(x, y, size, color)` - рисование квадрата
- `нарисовать_линию(x1, y1, x2, y2, color)` - рисование линии
- `нарисовать_треугольник(x1, y1, x2, y2, x3, y3, color)` - треугольник
- `нарисовать_звезду(x, y, outer_r, inner_r, rays, color)` - звезда
- `добавить_на_холст(canvas, object)` - добавление на холст
- `показать_холст(canvas)` - отображение холста

## Примеры программ

### Калькулятор

```
написать_строку("Простой калькулятор")
пусть a равна в_число(спросить("Введите первое число: "))
пусть b равна в_число(спросить("Введите второе число: "))
пусть операция равна спросить("Выберите операцию (плюс/минус/умножить/разделить): ")

если равно(операция, "плюс") то написать_строку(плюс("Результат: ", плюс(a, b)))
если равно(операция, "минус") то написать_строку(плюс("Результат: ", минус(a, b)))
если равно(операция, "умножить") то написать_строку(плюс("Результат: ", умножить(a, b)))
если равно(операция, "разделить") то написать_строку(плюс("Результат: ", разделить(a, b)))
```

### Рисование домика

```
пусть холст равна создать_холст(400, 400)

# Рисуем стены
пусть стены равна нарисовать_квадрат(100, 200, 200, 'коричневый')
добавить_на_холст(холст, стены)

# Рисуем крышу
пусть крыша равна нарисовать_треугольник(100, 200, 300, 200, 200, 100, 'красный')
добавить_на_холст(холст, крыша)

# Рисуем окно
пусть окно равна нарисовать_квадрат(175, 250, 50, 'голубой')
добавить_на_холст(холст, окно)

# Рисуем солнце
пусть солнце равна нарисовать_круг(350, 50, 30, 'желтый')
добавить_на_холст(холст, солнце)

показать_холст(холст)
```

### Игра "Угадай число"

```
написать_строку("Игра: Угадай число!")
пусть загаданное равна случайное_число(1, 100)
пусть попытки равна 0
пусть угадал равна ложь

пока не(угадал) повторить:
    пусть ввод равна спросить("Введите число от 1 до 100: ")
    пусть число равна в_число(ввод)
    пусть попытки равна плюс(попытки, 1)
    
    если равно(число, загаданное) то:
        написать_строку("Поздравляю! Ты угадал!")
        пусть угадал равна истина
    
    если больше(число, загаданное) то:
        написать_строку("Меньше!")
    
    если меньше(число, загаданное) то:
        написать_строку("Больше!")

написать_строку(плюс("Количество попыток: ", попытки))
```

## Расширение языка

Вы можете добавлять свои функции в интерпретатор:

```python
from core.interpreter import РусКодИнтерпретатор

интерпретатор = РусКодИнтерпретатор()

# Добавляем свою функцию
интерпретатор.функции['приветствовать'] = lambda имя: f"Привет, {имя}!"

# Используем
код = """
написать_строку(приветствовать("Алексей"))
"""

интерпретатор.выполнить(код)
```
